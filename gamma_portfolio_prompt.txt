== SECTION 5: 트러블슈팅 ==

SLIDE 18 — 트러블슈팅 ① JWT 자동 갱신
Problem: API 요청 중 Access Token 만료 시 강제 로그아웃 발생
Cause: 401 응답 처리 로직 미구현
Solution:
1. Axios Interceptor에서 401 감지
2. Refresh Token으로 새 Access Token 발급 (silentRefresh)
3. 실패한 원래 요청 자동 재시도
Result: 사용자 재로그인 없이 자연스러운 세션 유지

SLIDE 19 — 트러블슈팅 ② IoT 기기 제어 화면 성능
Problem: 기기제어 탭 재진입 시마다 API 중복 호출 발생
Cause: useEffect 의존성 설정 미흡으로 상태 재요청 반복
Solution: useRef로 마지막 조회 timestamp 추적
→ 일정 시간 이내 재진입 시 API 재호출 생략
Result: 불필요한 서버 요청 제거, 화면 로딩 속도 개선

SLIDE 20 — 트러블슈팅 ③ Expo SSE 알림 연결
Problem: React Native 환경에서 기본 EventSource API 미지원
Cause: 브라우저 전용 API라 모바일에서 동작 불가
Solution: @microsoft/fetch-event-source 라이브러리 적용
AbortController로 컴포넌트 언마운트 시 연결 정리
Result: 모바일에서 실시간 알림 정상 수신
